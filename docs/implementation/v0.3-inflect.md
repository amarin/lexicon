# v0.3 implementation write-up — inflection API

Consolidates the plan (`docs/plans/2026-10-01-v0.3-inflect.md`) and the
decisions taken with the owner on 2026-10-01. Builds on
[v0.1](v0.1-analysis.md) (the dictionary `Registry`); `Analyzer` and the
NER packages of [v0.2](v0.2-ner.md) are unchanged. No dependency changed.

## What was built

- `Registry.Inflect(word, kinds, from, want) []string` (`registry.go`,
  `snapshot.inflect` in `snapshot.go`): forms of a word by grammemes over
  gomorphy 1.3.0's `Dictionary.Inflect`. It pins the snapshot like `Parse`,
  so it is safe during `SetEnabled`/`Reload`.
- `NumeralGrammemes(n) []string` (`numeral.go`): the grammemes of a noun
  after a count in a nominative phrase.
- Scenario 22 (EN + RU), example `examples/inflect`, godoc examples, an
  integration test on the real base (`TestRealBaseInflect`: division and
  military unit type names).

## Decisions

- **D29. A registry method, not gomorphy readings in the public API.**
  `lexicon.Reading` keeps dropping `Word`/`Para`/`Form`/`Shard`; the method
  returns strings. A gomorphy reading is only valid for the snapshot it came
  from, which a host cannot see. Settles the API choice of Q-v03-10.
- **D30. Exact readings only.** Predicted readings are never inflected, in
  any dictionary kind, and there is no option for it: the forms would come
  from a guessed paradigm. A later need gets its own method.
- **D31. `from` selects the reading; the result is a list.** Homonyms are
  the caller's choice by grammemes. Distinct forms: dictionaries in registry
  order, readings in dictionary order, gomorphy's order within a reading
  (fewest grammemes differing from the source reading first). Hosts take
  the first.
- **D32. ё.** A dictionary that does not know the word as given is asked
  again with ё folded to е (TSV dictionaries are stored with е, D28); the
  base finds «посёлок» for «поселок» through gomorphy's character policy.
  Forms are returned as stored, so the base and a TSV dictionary can give
  two spellings of one form.
- **D33. Count agreement is a pure function** for the nominative phrase
  only; it returns grammemes, not a form, so it composes with `from` and
  `kinds`.
- **D34. Version numbers.** New exported API → 0.3.0; the patterns
  milestone moved to 0.4 (its plan file and `Q-v03-*` ids keep their names).
  `analyzerVersion` and `ner.extractorVersion` are not bumped.

## Known limits

- No sense separation («корпус» → «корпусы», «год» → «годов» before
  «лет»): hosts keep overrides or a `custom` dictionary selected by `kinds`.
- Multi-word terms are inflected word by word by the host.
- No base dictionary — no forms.
