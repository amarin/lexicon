# lexicon v0.1 — text analysis (textnorm, lexicon, basefetch, CLI): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

The plan is split in two files because of size:

- **this file** — overview, order, constraints, decisions, public API, Tasks 1–4 (module bootstrap, `textnorm`);
- [2026-09-24-v0.1-analysis-lexicon.md](2026-09-24-v0.1-analysis-lexicon.md) — Tasks 5–16 (`lexicon` types, profiles, `Analyzer`, lemma cache, `basefetch`, `Registry`, CLI, integration, docs) and **Open questions**.

**Goal:** A standalone Go module `github.com/amarin/lexicon` whose v0.1 gives hosts (first: genodex search P1) one text-analysis pipeline — orthography rule sets, a tokenizer that emits every token with byte + rune offsets, a gomorphy dictionary registry with hot reload, host-defined field profiles, and an `Analyzer` with an index mode (exactly genodex P1 behaviour) and a full mode (for NER in v0.2).

**Architecture:** Package `textnorm` is pure functions over strings (no dictionaries). The root package `lexicon` holds the dictionary `Registry` (gomorphy `.dat`/TSV files from a directory plus host-supplied built-ins; immutable, reference-counted snapshots swapped atomically), `Profile`s, and the `Analyzer`, which talks to dictionaries only through the `Dictionaries` interface so it is tested on fakes. `basefetch` (optional, isolated) downloads and compiles the OpenCorpora base dictionary. `cmd/lexicon` is a small CLI (`analyze`, `dicts list|fetch`). Code is ported from the genodex P1 plan (`../genodex/docs/plans/2026-09-24-search-p1-normalizer.md`, Tasks 1–8) and generalised per the spec.

**Tech Stack:** Go (`go 1.25.0` + `toolchain go1.27.1`: owner policy "current Go minus two minor versions", the same as gomorphy 1.2.0, spec item F), `github.com/amarin/gomorphy` ≥ v1.2.0 (items A, B, C, E of its NER-support spec), `golang.org/x/text/unicode/norm`, stdlib `testing` (unit, fuzz, benchmarks).

**Spec:** [docs/specs/2026-09-24-lexicon-design.md](../specs/2026-09-24-lexicon-design.md) (milestone v0.1). Also read: genodex P1 plan (source of ported code and regression tests), genodex `docs/search/normalization.md` (rules), gomorphy spec `../gomorphy-ner-support/docs/en/superpowers/specs/2026-09-24-ner-support-design.md` (library API lexicon depends on).

## Global Constraints

- Module path `github.com/amarin/lexicon`; the root package is `lexicon` (import `github.com/amarin/lexicon`), subpackages `textnorm`, `basefetch`, command `cmd/lexicon`.
- `go.mod`: `go 1.25.0` and `toolchain go1.27.1` (owner policy 2026-09-24: the `go` directive is the current Go release minus two minor versions — 1.27 now, so 1.25; gomorphy 1.2.0 declares the same, so requiring it does not raise the line). Neither `go get` nor `go mod tidy` may raise the `go` line: if a dependency's newest version needs a newer Go, pin the newest version that fits 1.25 and restore `go mod edit -go=1.25.0`. Raising the line follows the policy only (an owner step when a new Go minor ships). Sibling modules (owner decision 2026-09-25): local gomorphy is wired with a **local, uncommitted `go.work`** (`go work init . ../gomorphy`, or `../gomorphy-ner-support` / the matching worktree path); `go.work` and `go.work.sum` are in `.gitignore`; **never** a `replace` directive in `go.mod`. `go.mod` always lists a real gomorphy version: a tagged release, or before the release a pseudo-version of a pushed commit (`GOWORK=off go get github.com/amarin/gomorphy@<pushed commit>`); when no pushed commit exists yet, a placeholder (`v1.2.0`) is acceptable in branch commits — Placeholder caveat (checked 2026-09-25 on go1.27.1): `go.work` does not stop the go command from downloading the `go.mod` of each required version once third-party modules are in the graph (lexicon has `golang.org/x/text`), so a workspace build fails on a placeholder that no module source knows (`unknown revision`). If that happens, stop and ask the owner to push the gomorphy branch; push only with the owner's consent. `go mod tidy` ignores `go.work`: run it as `GOWORK=off go mod tidy`, and only while every version in `go.mod` is pushed. A tagged lexicon release requires a released gomorphy (≥ v1.2.0) and passes `GOWORK=off go build ./... && GOWORK=off go test ./...` against it (owner step); merges to `main` stay `git merge --ff-only`.
- Library dependencies: `github.com/amarin/gomorphy` and `golang.org/x/text` only. `basefetch` additionally imports `gomorphy/pkg/pymorphy` (pulls `amarin/logging`/zap) and is isolated. Tests: stdlib `testing` only. No logger anywhere: return errors, expose state (`List`, `Summary`).
- Language of code comments, error texts, docs, CLI output: English. Test fixtures: Russian text.
- Offsets contract (binding): offsets refer to the input string exactly as passed; every token carries byte (`Start`/`End`) and code-point (`RuneStart`/`RuneEnd`) offsets computed in one pass; UTF-16 via `textnorm.UTF16Offsets`; token boundaries fall on grapheme-cluster boundaries (combining marks belong to the preceding letter); `input[t.Start:t.End] == t.Raw`; hyphenated words are one `Word` token, parts via `SplitHyphen`; whitespace is not a token, `Punct` tokens are kept.
- `ModeIndex` reproduces genodex P1 behaviour; the P1 tests are ported as regression tests (the only intentional change of an expected string is the new `reform` flag, decision D12). Intentional behaviour change beyond the P1 tests: Latin homoglyphs inside Cyrillic words are replaced («Kот» → «кот», P1 indexed «от»; decision D2).
- `й` is kept; other combining marks are dropped; `ё→е` (both rule sets).
- Stop words: by gomorphy POS (`PREP`, `CONJ`, `PRCL`, `INTJ`) when **all** exact readings are service words; no stop list in code.
- Predicted readings are used only when no exact reading exists and **only from `KindBase` dictionaries**; abbreviation dictionaries never predict.
- A broken dictionary file never fails `Open`/`Reload`: it is listed with its error and does not take part in parsing.
- `Registry.Version()` = sha256 over (name, kind, content hash) of enabled loaded dictionaries in registry order; content hash = gomorphy `ContentHash()` for `.dat`, sha256 of the text for TSV.
- Hot reload from v0.1: snapshots are immutable, swapped atomically; retired snapshots close their dictionaries only after in-flight `Parse` calls finish (reference counting).
- Code organisation (genodex `DEVELOPER-PREFERENCES.md`): one struct (or named type with methods) per file, helpers in the file of their main function, snake_case file names; inter-package dependencies are interfaces in the consumer's `deps.go`. **No mockgen** (decision D24): fakes are hand-written in `*_test.go`, so the library takes no `go.uber.org/mock` dependency.
- Gate before every commit: `gofmt -l .` empty, `go vet ./...`, `go test ./... -count=1`; from Task 13 on also `go test -race ./... -count=1`. Code blocks in this plan are not guaranteed to be column-aligned: when `gofmt -l` lists a file you wrote, run `gofmt -w` on it (formatting only, no code changes).

The spec is followed except where listed. Each item is also referenced from the task that implements it.

| D1 | Package `lexicon` in module `github.com/amarin/lexicon` | Root package is `lexicon` (no `lexicon/lexicon` stutter) | Import path reads `lexicon.Registry`; subpackages unaffected |
| D2 | `Script` has `Mixed`; `Homoglyphs` («Kот», «Iоаннъ») | Owner decision 2026-09-24 (Q1): within one hyphen part of a word, if the part has a Cyrillic letter and every other letter is a key of `Rules.Homoglyphs`, the part is Cyrillic — one `ScriptCyrillic` word, homoglyphs replaced in `Form`, `Raw` and offsets untouched («Kот» → `Form` «кот»). Any other part splits at Cyrillic / non-Cyrillic letter boundaries as in P1 («Kотw» → «K» + «от» + «w»); parts without Cyrillic letters are unchanged («XIX-го» → «XIX» + «-» + «го»). `ScriptMixed` = a non-Cyrillic run that is not purely Latin (Greek, Latin+Greek…) | Homoglyphs are an OCR/typing issue, so both rule sets apply them. Intentional `ModeIndex` change: P1 indexed «от» in «Kот», lexicon indexes «кот» (Task 7 `TestAnalyzeIndexV01`). Other mixed words keep P1 behaviour |
| D3 | `Case`: Lower, Title, Upper, Mixed | Adds `CaseNone` (zero value: no cased letters — numbers, punctuation); `TokenKind` starts at 1 (`TokenWord`) | Zero values must not claim a kind/case |
| D4 | U+2010 → `-` listed under `PreReform` | Also in `Modern` | Typographic, not orthographic; otherwise `Modern` breaks hyphenated abbreviations |
| D5 | `Homoglyphs`: Latin look-alikes inside Cyrillic words | Replaces P1/spec `LatinInCyrillic` (Latin `i/I` adjacent to Cyrillic). Common table (A a B C c E e H K k M O o P p T X x y Y) in `Modern` and `PreReform`; `PreReform` adds `i→і`, `I→І` (its letter map then turns `і` into `и`). `Orthography` applies the same part rule as the tokenizer (a part = a maximal run of letters, combining marks and format characters), **before** lower-casing so that upper-case-only homoglyphs (B, H, M, T) fold too. Both rule sets get `Version` "2" | «Mississippi», «XIX», «MOCKBA», «HOME» (no Cyrillic letter) stay Latin — confirmed as intended by the owner 2026-09-24 (second part, Q10); `Form` of a token = `NormalizeWord` of its `Raw`; P1 mapped every Latin `i` to `и` |
| D6 | `Form` "" for punctuation | Also "" for `Symbol`; `Number` form = its ASCII digits (marks attached to digits dropped) | Symbols carry no lemma; `Raw` keeps the text |
| D7 | `SentenceEnd`: '.', '!', '?', ';' or line break | Set on `Punct` tokens `.` `!` `?` `;` `…` (always, also after an abbreviation — consumers combine with the preceding `Dotted`) and on the last token before a blank line or U+2029; a single line break is a space (owner decision Q5, 2026-09-24) | Tokenizer has no abbreviation knowledge; hard-wrapped archival text must not split multi-word matches |
| D8 | Grapheme-cluster boundaries | Approximation without new deps: marks, format characters (except U+200B) and emoji modifiers extend the preceding cluster; ZWJ + pictographic symbol joins; regional-indicator pairs join. Not modelled: `Prepend`, Hangul syllable rules (Hangul jamo are letters and stay in one word anyway) | Spec forbids deps beyond gomorphy/x/text; fuzz checks the modelled rules |
| D9 | `SplitHyphen(t Token) []Token` | Returns nil for a token without inner hyphen (or non-word); parts keep `Script`, recompute `Case`; `Dotted`/`SentenceEnd` only on the last part | Callers can tell "no parts" from "one part" |
| D10 | `Dictionaries` is an interface with `Parse(word, kinds)` | Adds `Version() string` | `Analyzer.Version()` and cache invalidation need the dictionary-set version |
| D11 | Parse rules live in the registry | `Registry.Parse` applies them **and** `Analyzer` re-applies them (drops non-base predictions) | Any `Dictionaries` implementation (fakes, hosts) gets P1 semantics |
| D12 | Flag `Reform` | Set whenever a lemma came from a pre-reform ending variant, in both modes; P1 regression expectation `покровскаго=покровский[]` becomes `…[reform]` | Additive information; lemma/term sets unchanged |
| D13 | P1: parts of a compound carry the whole token | `ModeIndex` part terms carry `SplitHyphen` part tokens (precise offsets); forms/lemmas identical to P1 | Better offsets for snippets |
| D14 | One-letter abbreviations only with a dot, flagged `Ambiguous` (P1 code did not enforce) | Dotted one-letter abbreviation → every lemma `FlagAmbiguous` even if single; abbreviation readings of one-letter forms without a dot are dropped | genodex `normalization.md` rule, now enforced |

```go
package textnorm

// Rules is an orthography rule set. Forms derived by a rule set are stored by
// hosts (search index), so any change of a table requires a new Version.
//
// The package-level Modern and PreReform values must not be modified; build a
// new Rules value to customise.
type Rules struct {
	// Name identifies the rule set, e.g. "modern", "prereform".
	Name string
	// Version is part of every derived version hash (Analyzer.Version).
	Version string
	// Letters replaces letters after lower-casing and canonical decomposition
	// (ѣ→е, і→и, ѳ→ф …). A replacement may be several letters (ѯ→кс).
	Letters map[rune]string
	// KeepMarks lists precomposed letters kept intact although they decompose
	// into a letter and a combining mark (й).
	KeepMarks []rune
	// DropFinalHardSign removes a final ъ from every hyphen part of a word
	// («Ивановъ» → «иванов»); applied by NormalizeWord only.
	DropFinalHardSign bool
	// Homoglyphs maps Latin letters that look like Cyrillic ones to those
	// Cyrillic letters (OCR and typing errors: «Kот», «Iоаннъ»). A word part
	// (a maximal run of letters and combining marks, so hyphens separate
	// parts) that has a Cyrillic letter and no other letters than keys of
	// Homoglyphs is Cyrillic: the tokenizer keeps it one ScriptCyrillic word
	// and Orthography replaces its homoglyphs. Parts with other Latin letters
	// («Kотw») or without Cyrillic letters («XIX») are left alone.
	Homoglyphs map[rune]rune
}
```

`textnorm/orthography.go`:

```go
package textnorm

import (
	"slices"
	"strings"
	"unicode"
	"unicode/utf8"

	"golang.org/x/text/unicode/norm"
)

// Orthography maps s to the comparison orthography of r: NFC, Latin
// homoglyphs of Cyrillic word parts replaced by r.Homoglyphs (before
// lower-casing, so upper-case-only homoglyphs fold too), lower case, combining
// marks and format characters removed except in r.KeepMarks letters, letters
// replaced by r.Letters. The final hard sign is kept: it is a word rule
// (NormalizeWord). The result is for comparison only; offsets never refer to
// it.
func Orthography(r Rules, s string) string {
	runes := []rune(norm.NFC.String(s))
	foldHomoglyphs(r.Homoglyphs, runes)

	var (
		b   strings.Builder
		enc [utf8.UTFMax]byte
		dec [4 * utf8.UTFMax]byte
	)

	b.Grow(len(s))

	for _, c := range runes {
		c = unicode.ToLower(c)

		switch {
		case slices.Contains(r.KeepMarks, c):
			b.WriteRune(c)
		case unicode.IsMark(c), unicode.Is(unicode.Cf, c):
		default:
			d := norm.NFD.Append(dec[:0], utf8.AppendRune(enc[:0], c)...)
			for len(d) > 0 {
				x, n := utf8.DecodeRune(d)
				d = d[n:]

				if unicode.IsMark(x) {
					continue
				}

				if rep, ok := r.Letters[x]; ok {
					b.WriteString(rep)

					continue
				}

				b.WriteRune(x)
			}
		}
	}

	return b.String()
}

// NormalizeWord is the form of a word for indexing and comparison:
// Orthography plus, when r.DropFinalHardSign is set, removal of a final ъ from
// every hyphen part («санктъ-петербургъ» → «санкт-петербург»).
func NormalizeWord(r Rules, w string) string {
	s := Orthography(r, w)
	if !r.DropFinalHardSign {
		return s
	}

	parts := strings.Split(s, "-")
	for i, p := range parts {
		parts[i] = strings.TrimSuffix(p, "ъ")
	}

	return strings.Join(parts, "-")
}

// foldHomoglyphs replaces, in place, the Latin homoglyphs h of every Cyrillic
// word part of runes (isCyrillicPart). A part is a maximal run of letters,
// combining marks and format characters except U+200B (which the tokenizer
// treats as a space); hyphens and all other code points separate parts.
func foldHomoglyphs(h map[rune]rune, runes []rune) {
	if len(h) == 0 {
		return
	}

	for i := 0; i < len(runes); {
		j := i
		for j < len(runes) && inWordPart(runes[j]) {
			j++
		}

		if j == i {
			i++

			continue
		}

		if isCyrillicPart(h, runes[i:j]) {
			for k := i; k < j; k++ {
				if m, ok := h[runes[k]]; ok {
					runes[k] = m
				}
			}
		}

		i = j
	}
}

// inWordPart reports whether c continues a word part: a letter, a combining
// mark or a format character other than U+200B.
func inWordPart(c rune) bool {
	return unicode.IsLetter(c) || unicode.IsMark(c) || (unicode.Is(unicode.Cf, c) && c != '\u200b')
}

// isCyrillicPart reports whether a word part has at least one Cyrillic letter
// and every other letter of it is a key of h (Rules.Homoglyphs). Non-letters
// (marks, format characters) are ignored.
func isCyrillicPart(h map[rune]rune, part []rune) bool {
	cyr := false

	for _, c := range part {
		switch {
		case !unicode.IsLetter(c):
		case unicode.Is(unicode.Cyrillic, c):
			cyr = true
		default:
			if _, ok := h[c]; !ok {
				return false
			}
		}
	}

	return cyr
}
```

Tokenization rules (write them into the `Tokenize` doc comment, as below):

1. A **word** is a maximal run of letters of one category — Cyrillic or non-Cyrillic — plus the extending code points of each letter, joined over single inner hyphens (`-`, U+2010) that have a letter of the same category on both sides. Categories come from letter runs (letters and extending code points between any other code points, i.e. hyphen parts): a run with a Cyrillic letter whose other letters are all keys of `Rules.Homoglyphs` is Cyrillic as a whole (its `Form` has the homoglyphs replaced by `NormalizeWord`, `Raw` is untouched); in any other run each letter keeps its own category (decision D2).
2. A **number** is a run of ASCII digits (with extending code points).
3. Every other visible code point is a one-cluster **punct** (`unicode.IsPunct`) or **symbol** token (everything else); a pair of regional indicators is one symbol; a ZWJ followed by a pictographic symbol (`So`) joins it.
4. Extending code points (marks, format characters except U+200B, emoji modifiers U+1F3FB–1F3FF) never start a token: they extend the preceding one or are skipped after whitespace / at the start.
5. Whitespace (plus U+200B) and control characters are skipped; a single line break is a space, a blank line (two breaks with only whitespace between, CRLF = one) or U+2029 sets `SentenceEnd` on the previous token (spec Q5); `.`, `!`, `?`, `;`, `…` punct tokens have `SentenceEnd`.

```go
// checkTokens verifies the offsets contract for toks of input: order, byte and
// rune offsets, Raw, grapheme-cluster boundaries as modelled by isExtend, and
// UTF-16 offsets. Shared by unit and fuzz tests.
func checkTokens(t *testing.T, input string, toks []Token) {
	t.Helper()

	prevEnd := 0

	for i, tk := range toks {
		if tk.Start < prevEnd || tk.End <= tk.Start || tk.End > len(input) {
			t.Fatalf("token %d %+v: bad span after %d in %q", i, tk, prevEnd, input)
		}

		if input[tk.Start:tk.End] != tk.Raw {
			t.Fatalf("token %d: input[%d:%d] = %q, Raw %q", i, tk.Start, tk.End, input[tk.Start:tk.End], tk.Raw)
		}

		if got := utf8.RuneCountInString(input[:tk.Start]); got != tk.RuneStart {
			t.Fatalf("token %d %q: RuneStart %d, want %d", i, tk.Raw, tk.RuneStart, got)
		}

		if got := tk.RuneStart + utf8.RuneCountInString(tk.Raw); got != tk.RuneEnd {
			t.Fatalf("token %d %q: RuneEnd %d, want %d", i, tk.Raw, tk.RuneEnd, got)

			t.Fatalf("token %d %q starts inside a grapheme cluster", i, tk.Raw)
```

```go
package textnorm

import "unicode"

// caseOf classifies the letter case of raw word text. A single upper-case
// letter is Title («И»).
func caseOf(raw string) Case {
	var upper, lower int

	firstUpper, seen, partsTitle, partStart := false, false, true, true

	for _, r := range raw {
		switch {
		case isHyphen(r):
			partStart = true

			continue
		case unicode.IsUpper(r):
			if !seen {
				firstUpper = true
			}

			upper++

			if !partStart {
				partsTitle = false
			}
		case unicode.IsLower(r):
			lower++

			if partStart {
				partsTitle = false
			}
		default:
			continue
		}

		seen, partStart = true, false
	}

	switch {
	case upper+lower == 0:
		return CaseNone
	case upper == 0:
		return CaseLower
	case lower == 0 && upper > 1:
		return CaseUpper
	case firstUpper && upper == 1, partsTitle:
		return CaseTitle
	}

	return CaseMixed
}
```

```go
package textnorm

import "unicode"

// tokenizer is the state of one Tokenize call.
type tokenizer struct {
	rules  Rules
	in     string
	p      []runePos
	out    []Token
	breaks int // line breaks since the last token (spec Q5)
}

// end is the byte offset of code point j (len(in) past the end).
func (t *tokenizer) end(j int) int {
	if j < len(t.p) {
		return t.p[j].off
	}

	return len(t.in)
}

func (t *tokenizer) scan() {
	for i := 0; i < len(t.p); {
		c := t.p[i].r

		switch {
		case isLineBreak(c):
			// A single line break is a space (hard-wrapped text keeps
			// «Нижний⏎Новгород» in one sentence); a blank line or a
			// paragraph separator ends the sentence (spec Q5).
			if c == '\r' && i+1 < len(t.p) && t.p[i+1].r == '\n' {
				i++
			}

			t.breaks++
			if t.breaks >= 2 || c == '\u2029' {
				t.markSentenceEnd()
			}

			i++
		case isSpace(c), isExtend(c), unicode.IsControl(c):
			i++
		case isDigit(c):
			i = t.number(i)
		case unicode.IsLetter(c):
			i = t.word(i)
		case unicode.IsPunct(c):
			j := t.clusterEnd(i + 1)
			t.emit(i, j, TokenPunct, "")

			if isSentencePunct(c) {
				t.markSentenceEnd()
			}

			i = j
		default:
			j := i + 1
			if isRegionalIndicator(c) && j < len(t.p) && isRegionalIndicator(t.p[j].r) {
				j++
			}

			j = t.clusterEnd(j)
			t.emit(i, j, TokenSymbol, "")
			i = j
		}
	}
}

// emit appends the token of code points [i, j) and returns it for further
// fields; the pointer is valid until the next emit.
func (t *tokenizer) emit(i, j int, kind TokenKind, form string) *Token {
	t.breaks = 0
	start, end := t.p[i].off, t.end(j)
	t.out = append(t.out, Token{
		Raw: t.in[start:end], Form: form, Start: start, End: end, RuneStart: i, RuneEnd: j, Kind: kind,
	})

	return &t.out[len(t.out)-1]
}

func (t *tokenizer) markSentenceEnd() {
	if n := len(t.out); n > 0 {
		t.out[n-1].SentenceEnd = true
	}
}

// clusterEnd extends a cluster ending before j over extending code points and
// over a pictographic symbol joined by ZWJ.
func (t *tokenizer) clusterEnd(j int) int {
	for j < len(t.p) {
		c := t.p[j].r
		if isExtend(c) || (t.p[j-1].r == zwj && unicode.Is(unicode.So, c)) {
			j++

			continue
		}

		break
	}

	return j
}

func (t *tokenizer) number(i int) int {
	j := i

	var form []byte

	for j < len(t.p) && isDigit(t.p[j].r) {
		form = append(form, byte(t.p[j].r))
		j = t.clusterEnd(j + 1)
	}

	t.emit(i, j, TokenNumber, string(form))

	return j
}

func (t *tokenizer) word(i int) int {
	j := t.wordEnd(i)
	raw := t.in[t.p[i].off:t.end(j)]

	tok := t.emit(i, j, TokenWord, NormalizeWord(t.rules, raw))
	tok.Script = t.script(i, j)
	tok.Case = caseOf(raw)
	tok.Dotted = j < len(t.p) && t.p[j].r == '.'

	return j
}

// wordEnd returns the end of the word starting at letter i: letters of the
// same category (Cyrillic or not) with their clusters, joined over single
// inner hyphens.
func (t *tokenizer) wordEnd(i int) int {
	cyr := t.p[i].cyr
	j := t.clusterEnd(i + 1)

	for j < len(t.p) {
		c := t.p[j].r
		letter := unicode.IsLetter(c) && t.p[j].cyr == cyr
		hyphen := isHyphen(c) && j+1 < len(t.p) && unicode.IsLetter(t.p[j+1].r) && t.p[j+1].cyr == cyr

		if !letter && !hyphen {
			break
		}

		j = t.clusterEnd(j + 1)
	}

	return j
}

// classify sets runePos.cyr before scanning. A letter run (letters and
// extending code points between any other code points, so hyphens end a run)
// that isCyrillicPart accepts is Cyrillic as a whole, its Latin homoglyphs
// included («Kот»); in any other run each letter keeps its own category
// («Kотw» → K | от | w, decision D2).
func (t *tokenizer) classify() {
	var run []rune

	for i := 0; i < len(t.p); {
		j := i
		run = run[:0]

		for j < len(t.p) && (unicode.IsLetter(t.p[j].r) || isExtend(t.p[j].r)) {
			run = append(run, t.p[j].r)
			j++
		}

		if j == i {
			i++

			continue
		}

		whole := isCyrillicPart(t.rules.Homoglyphs, run)
		for k := i; k < j; k++ {
			t.p[k].cyr = whole || unicode.Is(unicode.Cyrillic, t.p[k].r)
		}

		i = j
	}
}

// script of the word [i, j); a word is homogeneous in the Cyrillic category.
func (t *tokenizer) script(i, j int) Script {
	if t.p[i].cyr {
		return ScriptCyrillic
	}

	for k := i; k < j; k++ {
		if c := t.p[k].r; unicode.IsLetter(c) && !unicode.Is(unicode.Latin, c) {
			return ScriptMixed
		}
	}

	return ScriptLatin
}
```

```go
package textnorm

import "unicode"

// zwj is ZERO WIDTH JOINER.
const zwj = '‍'

// Tokenize splits input into tokens with byte and code-point offsets into
// input exactly as passed (input[t.Start:t.End] == t.Raw):
//
//  1. a word is a maximal run of letters of one category — Cyrillic or
//     non-Cyrillic — with the extending code points of each letter, joined
//     over single inner hyphens (-, U+2010) between letters of that category;
//     a hyphen part with a Cyrillic letter whose other letters are all keys
//     of r.Homoglyphs is Cyrillic as a whole («Kот», Form «кот»); in other
//     parts each letter keeps its own category («Kотw» → «K», «от», «w»);
//  2. a number is a run of ASCII digits;
//  3. any other visible code point is a one-cluster punct or symbol token; a
//     regional-indicator pair is one symbol; ZWJ joins a following pictographic
//     symbol;
//  4. extending code points (marks, format characters except U+200B, emoji
//     modifiers) never start a token: they extend the preceding one, or are
//     skipped after whitespace and at the start;
//  5. whitespace (and U+200B) and control characters are not tokens; a line
//     break sets SentenceEnd on the previous token, as do the punctuation
//     tokens . ! ? ; ….
//
// Grapheme clusters are approximated by rule 4 and the ZWJ/regional-indicator
// rules; Prepend characters are not modelled.
func Tokenize(r Rules, input string) []Token {
	t := tokenizer{rules: r, in: input, p: make([]runePos, 0, len(input))}
	for off, c := range input {
		t.p = append(t.p, runePos{off: off, r: c})
	}

	t.classify()
	t.scan()

	return t.out
}

func isDigit(r rune) bool { return r >= '0' && r <= '9' }

func isHyphen(r rune) bool { return r == '-' || r == '‐' }

// isExtend: code points that belong to the preceding grapheme cluster.
func isExtend(r rune) bool {
	return unicode.IsMark(r) ||
		(unicode.Is(unicode.Cf, r) && r != '​') ||
		(r >= 0x1F3FB && r <= 0x1F3FF)
}

func isSpace(r rune) bool { return unicode.IsSpace(r) || r == '​' }

func isLineBreak(r rune) bool {
	switch r {
	case '\n', '\r', '\v', '\f', '\u0085', ' ', ' ':
		return true
	}

	return false
}

func isSentencePunct(r rune) bool {
	switch r {
	case '.', '!', '?', ';', '…':
		return true
	}

	return false
}

func isRegionalIndicator(r rune) bool { return r >= 0x1F1E6 && r <= 0x1F1FF }
```

```go
// UTF16Offsets converts byte offsets of input to UTF-16 code-unit offsets (for
// JavaScript clients). Offsets may come in any order; the result is in the
// same order. An offset inside a code point counts that code point; invalid
// UTF-8 bytes count as one unit each (U+FFFD). Panics on an offset outside
// [0, len(input)].
func UTF16Offsets(input string, byteOffs ...int) []int {
	order := make([]int, len(byteOffs))
	for i := range order {
		order[i] = i
	}

	slices.SortFunc(order, func(a, b int) int { return cmp.Compare(byteOffs[a], byteOffs[b]) })

	out := make([]int, len(byteOffs))
	pos, units := 0, 0

	for _, k := range order {
		off := byteOffs[k]
		if off < 0 || off > len(input) {
			panic(fmt.Sprintf("textnorm: byte offset %d out of range [0, %d]", off, len(input)))
		}

		for pos < off {
			c, size := utf8.DecodeRuneInString(input[pos:])
			units += utf16.RuneLen(c)
			pos += size
		}

		out[k] = units
	}

	return out
}
```

`textnorm/split_hyphen.go`:

```go
package textnorm

import "unicode/utf8"

// SplitHyphen returns the hyphen-separated parts of a word token, each with
// offsets into the same input, its own Form and Case, the word's Script;
// Dotted and SentenceEnd go to the last part. nil when t is not a word or has
// no inner hyphen (or when its Form does not split into the same number of
// parts, which the built-in rule sets never cause).
func SplitHyphen(t Token) []Token {
	if t.Kind != TokenWord {
		return nil
	}

	raws := hyphenParts(t.Raw)
	if len(raws) < 2 {
		return nil
	}

	forms := hyphenParts(t.Form)
	if len(forms) != len(raws) {
		return nil
	}

	out := make([]Token, len(raws))
	for i, s := range raws {
		raw := t.Raw[s[0]:s[1]]
		out[i] = Token{
			Raw: raw, Form: t.Form[forms[i][0]:forms[i][1]],
			Start: t.Start + s[0], End: t.Start + s[1],
			RuneStart: t.RuneStart + s[2], RuneEnd: t.RuneStart + s[3],
			Kind: TokenWord, Script: t.Script, Case: caseOf(raw),
		}
	}

	last := &out[len(out)-1]
	last.Dotted, last.SentenceEnd = t.Dotted, t.SentenceEnd

	return out
}

// hyphenParts returns [byteStart, byteEnd, runeStart, runeEnd] of every
// hyphen-separated part of s (one element when s has no hyphen).
func hyphenParts(s string) [][4]int {
	var out [][4]int

	start, runeStart, n := 0, 0, 0

	for off, c := range s {
		if isHyphen(c) {
			out = append(out, [4]int{start, off, runeStart, n})
			start, runeStart = off+utf8.RuneLen(c), n+1
		}

		n++
	}

	return append(out, [4]int{start, len(s), runeStart, n})
}
```

```go
package textnorm

import (
	"strings"
	"unicode/utf8"
)

// ReformVariants returns modern spellings of a form with a pre-reform adjective
// ending, nil when the ending is not pre-reform. Analyzers try the variants in
// order only when the form itself has no exact dictionary reading and take the
// first one the dictionary knows; the indexed form stays as in the text.
//
//   - -яго → -его («синяго» → «синего»);
//   - -аго → -ого; after a sibilant (ж, ш, ч, щ) -ого, then -его: the ending
//     depends on stress («большаго» → «большого», «хорошаго» → «хорошего»);
//   - -ыя → -ые, -ой («новыя»);
//   - -ия → -ие, then -ой after к/г/х («покровския» → «покровской») or -ей
//     otherwise («синия» → «синей»).
func ReformVariants(form string) []string {
	switch {
	case strings.HasSuffix(form, "яго"):
		return []string{strings.TrimSuffix(form, "яго") + "его"}
	case strings.HasSuffix(form, "аго"):
		stem := strings.TrimSuffix(form, "аго")
		if endsWithAny(stem, "жшчщ") {
			return []string{stem + "ого", stem + "его"}
		}

		return []string{stem + "ого"}
	case strings.HasSuffix(form, "ыя"):
		stem := strings.TrimSuffix(form, "ыя")

		return []string{stem + "ые", stem + "ой"}
	case strings.HasSuffix(form, "ия"):
		stem := strings.TrimSuffix(form, "ия")
		if endsWithAny(stem, "кгх") {
			return []string{stem + "ие", stem + "ой"}
		}

		return []string{stem + "ие", stem + "ей"}
	}

	return nil
}

// endsWithAny reports whether the last letter of s is one of letters.
func endsWithAny(s, letters string) bool {
	r, size := utf8.DecodeLastRuneInString(s)

	return size > 0 && strings.ContainsRune(letters, r)
}
```
