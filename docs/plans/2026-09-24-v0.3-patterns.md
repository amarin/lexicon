# lexicon v0.3 — rule patterns, facts, tag-gated pattern sets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add sequence patterns to `rules` (span types, lemmas, grammemes, token kinds, groups with `?`/`*`/`+`, compiled to an NFA) with actions `Relabel`, `Boost` and `Emit Fact`, and run them inside `ner.Pipeline` so that domain naming rules («крестьянин … Иван Петров» → «Петров» is a patronymic) and relations («дочь X», «N лет») are data gated by document tags.

**Architecture:** `rules` compiles each `Pattern` into a Thompson-style program (`elem`/`split`/`jmp`/`save`/`match` instructions) and executes it with a backtracking matcher that memoizes visited `(instruction, position)` pairs (leftmost-first, greedy, linear in program × input). Patterns run over a `rules.Lattice` — the terms of one sentence plus the candidate spans starting at each term — which `ner` builds from its pre-resolution candidates. Actions mutate candidates (relabel/boost) or record pending facts; after resolution, facts whose argument spans survived become `Result.Facts` with indexes into `Result.Spans`.

**Tech Stack:** Go stdlib + `go.yaml.in/yaml/v3` (already required by v0.2 for rule files); lexicon v0.1 (`textnorm`, `lexicon`) and v0.2 (`gazetteer`, `rules`, `ner`, `internal/fakedict`).

## Decisions taken where the spec is silent or contradictory

- P1. **Input of patterns.** Spec pipeline order is "triggers → patterns → resolution", so patterns run over the *candidate lattice* (all live candidates, overlapping ones included), not over resolved spans. A `type` element consumes any candidate of that type starting at the current term and jumps to its end; alternative candidates are tried longest first.
- P2. **Granularity.** Token elements consume one *term* (punctuation included, so «, 25 лет» and «восприемники:» can be written); patterns never cross sentence ends (`gazetteer.Text.Sentences`, with the v0.2 abbreviation-dot rule).
- P3. **Semantics:** leftmost-first, greedy `?`/`*`/`+` (no lazy quantifiers); matches of one pattern in a sentence do not overlap; empty matches are ignored.
- P4. **Selectors** accept alternatives with `|` (`type: surname|patronymic`, `lemma: сын|дочь`). `any: true` matches one term. Exactly one selector (or `group`) per element.
- P5. **Roles.** `role` on an element captures what it consumed: a candidate (type element) or a term range (other elements, groups). Repeated roles keep the last iteration.
- P6. **Relabel** on a span role (owner decision 2026-09-24, answer 13; replaces the earlier "drop the hits" rule): if a live candidate of the target type already covers the same range, the source candidate is removed, the existing one gets `+Weight` and context and keeps its own dictionary hits — so the relabelled span's `Refs` are the gazetteer refs of the new type on that range (e.g. a patronymic record «Петров»). Otherwise the candidate's type changes in place, its dictionary hits (refs, canonical forms, attrs) are dropped (`Refs` empty), its normal forms become lemma sequences and it is flagged `Candidate`. **In both cases the previous reading is kept as an alternative** of the relabelled candidate (v0.2 `candidate.alts`, decision D14): its old type, `Refs`, `Normal` and `Attrs`, scored with its own type and origin, with evidence `relabelled by pattern <name>` (evidence only with `Explain`); it surfaces as `Span.Alternatives` sorted together with the resolution losers (score desc, type asc). A relabel alternative never sets `Ambiguous` — the pattern decided. **Relabel on a token role** creates a new `Candidate` span of the target type over those terms (needed so that «25» in «25 лет» can be a fact argument — the spec's `Args map[role]spanIndex` admits only spans); it has no previous reading, so no relabel alternative.
- P7. **Weights:** `Relabel.Weight` and `Boost.Weight` default to 1. Pattern-created candidates score with the trigger origin weight. Relabel/boost give context (satisfy `RequiresContext`).
- P8. **Facts** are recorded during pattern application with candidate pointers and materialized after resolution and the `Types` filter; a fact is dropped when any argument candidate was not output. Identical facts (kind + args) are de-duplicated. `Fact` gains `Rule` (pattern name) for explainability — an addition to the spec's `Fact{Kind, Args}`.
- P9. **Validation:** `Emit` arguments must name roles that are bound only to type elements or relabelled earlier in the same pattern; unknown roles, empty kinds and zero actions are compile errors. `repeat` is a typed scalar (`Repeat`, owner decision 2026-09-24, Q-v03-9): values other than `""`, `"?"`, `"*"`, `"+"` fail at load time with the line number.
- P10. Patterns are applied in book order (file → set → pattern), each on the candidate state left by the previous one; a pattern's matches are computed on one lattice snapshot per sentence and then acted on in order.
- P11. **Source positions** (owner decision 2026-09-24, extends v0.2 D15): `Pattern` and `Element` (groups included) carry an unexported source line filled by `setPositions`. A pattern compile error reads `<file>:<line>: <set>/pattern "<name>": <message>` (`pattern <index>` when unnamed); the line is the offending element's (via internal `lineError`) or, for pattern-level and action errors, the pattern's.

```go
package rules

// Element is one step of a Pattern. Exactly one of Type, Lemma, Grammeme,
// Token, Any or Group is set. Selector strings accept alternatives: "a|b".
type Element struct {
	Type     string    `yaml:"type,omitempty"`     // candidate span type(s)
	Lemma    string    `yaml:"lemma,omitempty"`    // lemma or form(s) of one term
	Grammeme string    `yaml:"grammeme,omitempty"` // grammeme(s) in any lemma tag of one term
	Token    string    `yaml:"token,omitempty"`    // token kind(s): word, number, punct, symbol
	Any      bool      `yaml:"any,omitempty"`      // any one term
	Group    []Element `yaml:"group,omitempty"`    // nested sequence
	Repeat   Repeat    `yaml:"repeat,omitempty"`   // "", "?", "*", "+" (greedy); quote in YAML
	Role     string    `yaml:"role,omitempty"`     // capture name for actions

	line int // source line, set by Load (decision P11)
}

func (e Element) hasSelector() bool {
	return e.Type != "" || e.Lemma != "" || e.Grammeme != "" || e.Token != "" || e.Any
}
```

```go
package rules

import (
	"fmt"
	"slices"

	"go.yaml.in/yaml/v3"
)

// Repeat is how often an element may match; all repetitions are greedy.
// YAML: a quoted scalar "", "?", "*" or "+" (unquoted * and ? are YAML
// indicators).
type Repeat uint8

const (
	// RepeatOnce: exactly once ("" or omitted; zero value).
	RepeatOnce Repeat = iota
	// RepeatOptional: zero or one ("?").
	RepeatOptional
	// RepeatZeroOrMore: zero or more ("*").
	RepeatZeroOrMore
	// RepeatOneOrMore: one or more ("+").
	RepeatOneOrMore
)

// repeatMarks are the YAML markers, indexed by Repeat.
var repeatMarks = []string{"", "?", "*", "+"}

func (r Repeat) String() string {
	if int(r) < len(repeatMarks) {
		return repeatMarks[r]
	}
	return fmt.Sprintf("Repeat(%d)", uint8(r))
}

// MarshalYAML implements yaml.Marshaler.
func (r Repeat) MarshalYAML() (any, error) { return r.String(), nil }

// UnmarshalYAML implements yaml.Unmarshaler; anything but "", "?", "*" or
// "+" is an error naming the line.
func (r *Repeat) UnmarshalYAML(value *yaml.Node) error {
	if value.Kind != yaml.ScalarNode {
		return fmt.Errorf("line %d: repeat: want \"?\", \"*\" or \"+\"", value.Line)
	}
	i := slices.Index(repeatMarks, value.Value)
	if i < 0 {
		return fmt.Errorf("line %d: unknown repeat %q (want \"?\", \"*\" or \"+\", quoted)", value.Line, value.Value)
	}
	*r = Repeat(i)
	return nil
}
```

```go
package rules

import (
	"errors"
	"fmt"
	"slices"
	"strings"

	"github.com/amarin/lexicon"
	"github.com/amarin/lexicon/textnorm"
)

var tokenKinds = map[string]textnorm.TokenKind{
	"word":   textnorm.TokenWord,
	"number": textnorm.TokenNumber,
	"punct":  textnorm.TokenPunct,
	"symbol": textnorm.TokenSymbol,
}

// selector is the compiled test of one non-group element.
type selector struct {
	types     []string
	lemmas    keyword
	hasLemmas bool
	grammemes []string
	kinds     []textnorm.TokenKind
	any       bool
}

func newSelector(e Element) (*selector, error) {
	n := 0
	for _, set := range []bool{e.Type != "", e.Lemma != "", e.Grammeme != "", e.Token != "", e.Any} {
		if set {
			n++
		}
	}
	if n != 1 {
		return nil, errors.New("an element needs exactly one of type, lemma, grammeme, token, any or group")
	}
	s := &selector{any: e.Any}
	switch {
	case e.Type != "":
		if s.types = splitAlt(e.Type); len(s.types) == 0 {
			return nil, fmt.Errorf("empty type %q", e.Type)
		}
	case e.Lemma != "":
		k, err := newKeyword(e.Lemma, false)
		if err != nil {
			return nil, err
		}
		s.lemmas, s.hasLemmas = k, true
	case e.Grammeme != "":
		if s.grammemes = splitAlt(e.Grammeme); len(s.grammemes) == 0 {
			return nil, fmt.Errorf("empty grammeme %q", e.Grammeme)
		}
	case e.Token != "":
		for _, name := range splitAlt(e.Token) {
			k, ok := tokenKinds[name]
			if !ok {
				return nil, fmt.Errorf("unknown token kind %q (want word, number, punct or symbol)", name)
			}
			s.kinds = append(s.kinds, k)
		}
		if len(s.kinds) == 0 {
			return nil, fmt.Errorf("empty token kind %q", e.Token)
		}
	}
	return s, nil
}

// spans reports whether the selector consumes candidate spans.
func (s *selector) spans() bool { return s.types != nil }

func (s *selector) matchSpan(sp LatticeSpan) bool { return slices.Contains(s.types, sp.Type) }

func (s *selector) matchTerm(t *lexicon.Term) bool {
	switch {
	case s.any:
		return true
	case s.hasLemmas:
		return s.lemmas.match(t)
	case s.grammemes != nil:
		for _, l := range t.Lemmas {
			if l.Flags&lexicon.FlagUnknown != 0 {
				continue
			}
			for _, g := range s.grammemes {
				if hasGrammeme(l.Tag, g) {
					return true
				}
			}
		}
		return false
	default:
		return slices.Contains(s.kinds, t.Token.Kind)
	}
}

func hasGrammeme(tag, g string) bool {
	for _, f := range strings.FieldsFunc(tag, func(r rune) bool { return r == ',' || r == ' ' }) {
		if f == g {
			return true
		}
	}
	return false
}

func splitAlt(s string) []string {
	var out []string
	for _, p := range strings.Split(s, "|") {
		if p = strings.TrimSpace(p); p != "" {
			out = append(out, p)
		}
	}
	return out
}
```

`rules/compiler.go`:

```go
package rules

import (
	"errors"
	"fmt"
	"maps"
	"slices"
)

// compiler turns a Pattern into a Program (Thompson construction).
type compiler struct {
	insts    []inst
	roles    []string
	spanRole map[string]bool // role → bound only to type elements
}

// compilePattern compiles pt. Messages do not repeat the pattern name
// (compileSet prefixes "<file>:<line>: <set>/pattern \"<name>\""); element
// errors are *lineError with the element's source line.
func compilePattern(set string, pt Pattern) (*Program, error) {
	if pt.Name == "" {
		return nil, errors.New("pattern without name")
	}
	if len(pt.Elements) == 0 {
		return nil, errors.New("no elements")
	}
	c := &compiler{spanRole: map[string]bool{}}
	if err := c.seq(pt.Elements); err != nil {
		return nil, err
	}
	c.emit(inst{op: opMatch})
	actions, err := c.actions(pt.Actions)
	if err != nil {
		return nil, err
	}
	return &Program{name: pt.Name, set: set, insts: c.insts, roles: c.roles, actions: actions}, nil
}

func (c *compiler) emit(in inst) int {
	c.insts = append(c.insts, in)
	return len(c.insts) - 1
}

func (c *compiler) slot(role string) int {
	i := slices.Index(c.roles, role)
	if i < 0 {
		c.roles = append(c.roles, role)
		i = len(c.roles) - 1
	}
	return i
}

func (c *compiler) markRole(role string, span bool) {
	if prev, ok := c.spanRole[role]; ok {
		c.spanRole[role] = prev && span
		return
	}
	c.spanRole[role] = span
}

func (c *compiler) seq(es []Element) error {
	for _, e := range es {
		if err := c.elem(e); err != nil {
			return err
		}
	}
	return nil
}

// elem compiles repetition around once(e); greedy: split prefers the body.
func (c *compiler) elem(e Element) error {
	switch e.Repeat {
	case RepeatOnce:
		return c.once(e)
	case RepeatOptional:
		split := c.emit(inst{op: opSplit})
		if err := c.once(e); err != nil {
			return err
		}
		c.insts[split].x, c.insts[split].y = split+1, len(c.insts)
	case RepeatZeroOrMore:
		split := c.emit(inst{op: opSplit})
		if err := c.once(e); err != nil {
			return err
		}
		c.emit(inst{op: opJmp, x: split})
		c.insts[split].x, c.insts[split].y = split+1, len(c.insts)
	case RepeatOneOrMore:
		start := len(c.insts)
		if err := c.once(e); err != nil {
			return err
		}
		split := c.emit(inst{op: opSplit})
		c.insts[split].x, c.insts[split].y = start, split+1
	default: // only a Repeat built in Go; YAML input fails at load
		return atLine(e.line, fmt.Errorf("unknown repeat %s", e.Repeat))
	}
	return nil
}

func (c *compiler) once(e Element) error {
	slot := -1
	if e.Role != "" {
		slot = c.slot(e.Role)
		c.emit(inst{op: opSave, slot: 2 * slot})
	}
	if len(e.Group) > 0 {
		if e.hasSelector() {
			return atLine(e.line, errors.New("an element with a group cannot also have a selector"))
		}
		if e.Role != "" {
			c.markRole(e.Role, false)
		}
		if err := c.seq(e.Group); err != nil {
			return err
		}
	} else {
		sel, err := newSelector(e)
		if err != nil {
			return atLine(e.line, err)
		}
		if e.Role != "" {
			c.markRole(e.Role, sel.spans())
		}
		c.emit(inst{op: opElem, sel: sel, slot: slot})
	}
	if e.Role != "" {
		c.emit(inst{op: opSave, slot: 2*slot + 1})
	}
	return nil
}

// actions validates actions (decision P9) and applies default weights.
func (c *compiler) actions(as []Action) ([]Action, error) {
	if len(as) == 0 {
		return nil, errors.New("no actions")
	}
	relabelled := map[string]bool{}
	isSpan := func(role string) bool { return c.spanRole[role] || relabelled[role] }
	out := make([]Action, 0, len(as))
	for i, a := range as {
		n := 0
		for _, set := range []bool{a.Relabel != nil, a.Boost != nil, a.Emit != nil} {
			if set {
				n++
			}
		}
		if n != 1 {
			return nil, fmt.Errorf("action %d: want exactly one of relabel, boost, emit", i)
		}
		switch {
		case a.Relabel != nil:
			r := *a.Relabel
			if _, ok := c.spanRole[r.Role]; !ok {
				return nil, fmt.Errorf("action %d: unknown role %q", i, r.Role)
			}
			if r.Type == "" {
				return nil, fmt.Errorf("action %d: relabel without type", i)
			}
			if r.Weight == 0 {
				r.Weight = 1
			}
			relabelled[r.Role] = true
			out = append(out, Action{Relabel: &r})
		case a.Boost != nil:
			b := *a.Boost
			if _, ok := c.spanRole[b.Role]; !ok {
				return nil, fmt.Errorf("action %d: unknown role %q", i, b.Role)
			}
			if !isSpan(b.Role) {
				return nil, fmt.Errorf("action %d: boost role %q is not a span", i, b.Role)
			}
			if b.Weight == 0 {
				b.Weight = 1
			}
			out = append(out, Action{Boost: &b})
		default:
			e := *a.Emit
			if e.Kind == "" {
				return nil, fmt.Errorf("action %d: emit without kind", i)
			}
			if len(e.Args) == 0 {
				return nil, fmt.Errorf("action %d: emit without args", i)
			}
			factRoles := make([]string, 0, len(e.Args))
			for k := range e.Args {
				factRoles = append(factRoles, k)
			}
			slices.Sort(factRoles)
			for _, factRole := range factRoles {
				role := e.Args[factRole]
				if _, ok := c.spanRole[role]; !ok {
					return nil, fmt.Errorf("action %d: emit arg %q: unknown role %q", i, factRole, role)
				}
				if !isSpan(role) {
					return nil, fmt.Errorf("action %d: emit arg %q: role %q is not a span (bind it to a type element or relabel it first)", i, factRole, role)
				}
			}
			e.Args = maps.Clone(e.Args)
			out = append(out, Action{Emit: &e})
		}
	}
	return out, nil
}
```

```go
package rules

// matcher executes a program with backtracking and a visited set over
// (instruction, position): each pair is explored at most once, which keeps
// leftmost-first semantics and bounds work by len(insts) × (n+1).
type matcher struct {
	insts   []inst
	l       Lattice
	n       int
	visited []bool
	caps    []int // 2 per role: start, end
	spans   []int // 1 per role: LatticeSpan.ID or -1
}

func (m *matcher) reset() {
	clear(m.visited)
	for i := range m.caps {
		m.caps[i] = -1
	}
	for i := range m.spans {
		m.spans[i] = -1
	}
}

// run returns the end position of the first accepting path from (pc, pos).
func (m *matcher) run(pc, pos int) (int, bool) {
	for {
		k := pc*(m.n+1) + pos
		if m.visited[k] {
			return 0, false
		}
		m.visited[k] = true
		in := &m.insts[pc]
		switch in.op {
		case opMatch:
			return pos, true
		case opJmp:
			pc = in.x
		case opSplit:
			if end, ok := m.run(in.x, pos); ok {
				return end, true
			}
			pc = in.y
		case opSave:
			role, start := in.slot/2, in.slot%2 == 0
			oldCap, oldSpan := m.caps[in.slot], m.spans[role]
			m.caps[in.slot] = pos
			if start {
				m.spans[role] = -1
			}
			if end, ok := m.run(pc+1, pos); ok {
				return end, true
			}
			m.caps[in.slot], m.spans[role] = oldCap, oldSpan
			return 0, false
		case opElem:
			if pos >= m.n {
				return 0, false
			}
			if in.sel.spans() {
				for _, sp := range m.l.SpansAt(pos) {
					if sp.End <= pos || sp.End > m.n || !in.sel.matchSpan(sp) {
						continue
					}
					old := -1
					if in.slot >= 0 {
						old, m.spans[in.slot] = m.spans[in.slot], sp.ID
					}
					if end, ok := m.run(pc+1, sp.End); ok {
						return end, true
					}
					if in.slot >= 0 {
						m.spans[in.slot] = old
					}
				}
				return 0, false
			}
			if !in.sel.matchTerm(m.l.Term(pos)) {
				return 0, false
			}
			pc, pos = pc+1, pos+1
		}
	}
}
```

```go
// FindAll returns the non-overlapping, non-empty matches of the program in
// l, scanning start positions left to right.
func (p *Program) FindAll(l Lattice) []PatternMatch {
	n := l.Len()
	m := &matcher{
		insts:   p.insts,
		l:       l,
		n:       n,
		visited: make([]bool, len(p.insts)*(n+1)),
		caps:    make([]int, 2*len(p.roles)),
		spans:   make([]int, len(p.roles)),
	}
	var out []PatternMatch
	for start := 0; start < n; {
		m.reset()
		end, ok := m.run(0, start)
		if !ok || end == start {
			start++
			continue
		}
		out = append(out, p.match(m, start, end))
		start = end
	}
	return out
}

func (p *Program) match(m *matcher, start, end int) PatternMatch {
	pm := PatternMatch{Start: start, End: end, Roles: map[string]Capture{}}
	for i, role := range p.roles {
		s, e := m.caps[2*i], m.caps[2*i+1]
		if s < 0 || e < 0 {
			continue
		}
		pm.Roles[role] = Capture{Start: s, End: e, Span: m.spans[i]}
	}
	return pm
}
```

```go
package ner

import (
	"sort"

	"github.com/amarin/lexicon"
	"github.com/amarin/lexicon/rules"
)

// lattice exposes one sentence (terms [t0, t1)) and the live candidates
// inside it to rules patterns. Span IDs are indexes into state.cands.
type lattice struct {
	s      *state
	t0, t1 int
	starts map[int][]rules.LatticeSpan
}

func (s *state) lattice(seg [2]int) *lattice {
	l := &lattice{s: s, t0: seg[0], t1: seg[1], starts: map[int][]rules.LatticeSpan{}}
	for i, c := range s.cands {
		if c.removed {
			continue
		}
		ts, te := s.tx.TermIndex(c.start), s.tx.TermIndex(c.end-1)+1
		if ts < l.t0 || te > l.t1 {
			continue
		}
		k := ts - l.t0
		l.starts[k] = append(l.starts[k], rules.LatticeSpan{ID: i, Type: c.typ, End: te - l.t0})
	}
	for _, sp := range l.starts {
		sort.SliceStable(sp, func(a, b int) bool {
			if sp[a].End != sp[b].End {
				return sp[a].End > sp[b].End
			}
			return sp[a].ID < sp[b].ID
		})
	}
	return l
}

func (l *lattice) Len() int                          { return l.t1 - l.t0 }
func (l *lattice) Term(i int) *lexicon.Term          { return &l.s.terms[l.t0+i] }
func (l *lattice) SpansAt(i int) []rules.LatticeSpan { return l.starts[i] }
```

```go
package ner

import (

// applyPatterns runs every active pattern over every sentence (decision P10).
func (s *state) applyPatterns(progs []*rules.Program) {
	for _, prog := range progs {
		for _, seg := range s.tx.Sentences() {
			l := s.lattice(seg)
			for _, m := range prog.FindAll(l) {
				s.act(prog, l, m)
			}
		}
	}
}

// act runs the actions of one match in order.
func (s *state) act(prog *rules.Program, l *lattice, m rules.PatternMatch) {
	bound := map[string]*candidate{}
	for role, cp := range m.Roles {
		if cp.Span >= 0 && !s.cands[cp.Span].removed {
			bound[role] = s.cands[cp.Span]
		}
	}
	for _, a := range prog.Actions() {
		switch {
		case a.Relabel != nil:
			cp, ok := m.Roles[a.Relabel.Role]
			if !ok {
				continue
			}
			if c := s.relabel(prog.Name(), l, cp, bound[a.Relabel.Role], a.Relabel); c != nil {
				bound[a.Relabel.Role] = c
			}
		case a.Boost != nil:
			c := bound[a.Boost.Role]
			if c == nil {
				continue
			}
			c.bonus += float64(a.Boost.Weight)
			c.context = true
			s.note(c, "pattern %s boost %+g", prog.Name(), float64(a.Boost.Weight))
		case a.Emit != nil:
			f := pendingFact{kind: a.Emit.Kind, rule: prog.Name(), args: map[string]*candidate{}}
			complete := true
			for factRole, role := range a.Emit.Args {
				c := bound[role]
				if c == nil {
					complete = false
					break
				}
				f.args[factRole] = c
			}
			if complete {
				s.facts = append(s.facts, f)
			}
		}
	}
}

// relabel implements decision P6. c is the candidate captured by the role
// (nil for a term capture). It returns the candidate now bound to the role.
func (s *state) relabel(rule string, l *lattice, cp rules.Capture, c *candidate, r *rules.Relabel) *candidate {
	w := float64(r.Weight)
	if c != nil {
		if c.typ == r.Type {
			c.bonus += w
			c.context = true
			s.note(c, "pattern %s keeps %s", rule, r.Type)
			return c
		}
		for _, o := range s.cands {
			if o != c && !o.removed && o.typ == r.Type && o.start == c.start && o.end == c.end {
				// The target type's own gazetteer hits (refs) win; the source
				// reading becomes an alternative.
				c.removed = true
				s.note(c, "relabelled by pattern %s", rule)
				o.alts = append(o.alts, c)
				o.bonus += w
				o.context = true
				s.note(o, "pattern %s relabel %s → %s (existing)", rule, c.typ, r.Type)
				return o
			}
		}
		// Keep the previous reading as an alternative: a detached copy
		// (not in s.cands, so it never competes in resolution).
		prev := *c
		prev.evidence = slices.Clone(c.evidence)
		prev.alts = nil
		s.note(&prev, "relabelled by pattern %s", rule)
		c.alts = append(c.alts, &prev)
		s.note(c, "pattern %s relabel %s → %s", rule, c.typ, r.Type)
		c.typ, c.hits, c.normals = r.Type, nil, s.lemmaNormals(c.start, c.end)
		c.flags |= Candidate
		c.bonus += w
		c.context = true
		return c
	}
	a, b, ok := s.positions(l.t0+cp.Start, l.t0+cp.End)
	if !ok {
		return nil
	}
	nc := &candidate{
		start: a, end: b, typ: r.Type, origin: originPattern,
		normals: s.lemmaNormals(a, b), flags: Candidate, bonus: w, context: true,
	}
	s.note(nc, "pattern %s label %s", rule, r.Type)
	s.cands = append(s.cands, nc)
	return nc
}

// positions maps terms [ts, te) to content positions [a, b).
func (s *state) positions(ts, te int) (int, int, bool) {
	n := s.tx.Len()
	a := sort.Search(n, func(p int) bool { return s.tx.TermIndex(p) >= ts })
	b := sort.Search(n, func(p int) bool { return s.tx.TermIndex(p) >= te })
	return a, b, a < b
}
```

```go
package ner

import (
	"fmt"
	"slices"
	"strings"
)

// buildFacts keeps facts whose argument candidates were output (index maps
// candidates to Result.Spans positions) and removes duplicates.
func (s *state) buildFacts(index map[*candidate]int) []Fact {
	var out []Fact
	seen := map[string]bool{}
	for _, f := range s.facts {
		args := make(map[string]int, len(f.args))
		ok := true
		for role, c := range f.args {
			i, found := index[c]
			if !found {
				ok = false
				break
			}
			args[role] = i
		}
		if !ok {
			continue
		}
		if key := factKey(f.kind, args); !seen[key] {
			seen[key] = true
			out = append(out, Fact{Kind: f.kind, Args: args, Rule: f.rule})
		}
	}
	return out
}

func factKey(kind string, args map[string]int) string {
	roles := make([]string, 0, len(args))
	for r := range args {
		roles = append(roles, r)
	}
	slices.Sort(roles)
	var b strings.Builder
	b.WriteString(kind)
	for _, r := range roles {
		fmt.Fprintf(&b, "|%s=%d", r, args[r])
	}
	return b.String()
}
```

```go
import (
```

```go
// factJSON is one JSONL fact line of extract.
type factJSON struct {
	Doc  int            `json:"doc"`
	Fact string         `json:"fact"`
	Args map[string]int `json:"args"`
	Rule string         `json:"rule,omitempty"`
}

func newFactJSON(doc int, f ner.Fact) factJSON {
	return factJSON{Doc: doc, Fact: f.Kind, Args: f.Args, Rule: f.Rule}
}

// describeFact renders "role=«surface» …" with roles sorted.
func describeFact(f ner.Fact, spans []ner.Span) string {
	roles := make([]string, 0, len(f.Args))
	for r := range f.Args {
		roles = append(roles, r)
	}
	slices.Sort(roles)
	parts := make([]string, len(roles))
	for i, r := range roles {
		parts[i] = fmt.Sprintf("%s=«%s»", r, spans[f.Args[r]].Surface)
	}
	return strings.Join(parts, " ")
}
```

## Open questions

- Q-v03-1. **Relabel and refs** (P6) — RESOLVED 2026-09-24 (owner, answer 13): the previous type with its `Refs`, `Normal` and `Attrs` is kept as a `Span.Alternatives` entry (evidence `relabelled by pattern <name>`); the relabelled span's `Refs` are the gazetteer refs of the new type on that range when such a record exists (the existing-target branch), else empty. Implemented in Task 4.
- Q-v03-2. **Lazy quantifiers** (`*?`) are not supported; `any*` is greedy, so «[estate] any* [given] [surname]» binds the *last* name pair in a sentence. Needed for multi-person sentences?
- Q-v03-3. **Negation elements** (`not`) are not in the spec and not implemented.
- Q-v03-4. **Facts in golden sets:** `nertest` scores spans only. Add fact cases (`"facts": [{"kind": …, "args": {"child": "Мария"}}]`) to JSONL?
- Q-v03-5. **Token-role relabel creating spans** (P6) extends the spec (`Relabel` "changes a span type"). Alternative: a separate `Label` action. Confirm the naming.
- Q-v03-6. **`Fact.Rule`** is an addition to the spec's `Fact{Kind, Args}`; keep?
- Q-v03-7. **Pattern application order** (P10): later patterns see earlier patterns' relabels. Should sets have explicit priorities instead of file order?
- Q-v03-8. «восприемники: …» (lists of persons after a colon) needs repeated role captures (all iterations, not the last one). Out of scope for v0.3 as specified; propose `role` lists in a later version.
- Q-v03-9. **Repeat markers in YAML.** RESOLVED 2026-09-24 (owner): `Element.Repeat` is a typed `Repeat` (`RepeatOnce` = `""`, `RepeatOptional` `"?"`, `RepeatZeroOrMore` `"*"`, `RepeatOneOrMore` `"+"`) with `UnmarshalYAML`/`MarshalYAML`; any other value fails at load as `<file>:<line>: unknown repeat …` (Task 1, `TestLoadPatternsBadRepeat`).
